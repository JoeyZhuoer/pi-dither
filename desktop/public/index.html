Desktop / Field guide

Your main agent gets the big window.

Drag title bars. Resize from the lower-right corner. Minimize to the taskbar. Windows open at the narrowest usable width with a medium height—main, children, observers and utilities have their own minimum widths—and they only get taller or shorter with the app when you have not resized them yourself. Any manual resize is saved for that window. Hidden windows stay hidden. Arrange resets the layout.

The desktop usage chart follows the selected agent: input, output, cache, reported cost and context occupancy. Click its heading for details. Unknown usage is shown as —; provisional turn usage is not added to session totals.

Keyboard: focus a title bar and use arrow keys to move; Shift + arrows to resize. Ctrl/Cmd + Enter sends a message.

No empty subagent windows are created at startup. Use + Subagent to create a manual draft, then Launch to start it. They are separate core Pi sessions defaulting to read, grep, find and ls tools—no concurrent file writers. Their results can be inserted into the main draft for your review.

The main agent defaults to Pi's filesystem and shell tools. This local interface is not a sandbox. Model requests use your configured Pi provider. Authentication stays on the server.

Use Windows for the windows you keep, and the ⚙ button on the right to choose which of them appear in the bottom bar and to open any of them; the choice is remembered. The same dialog can hide the Thinking panel on the right rail, where the selected agent's reasoning streams while the conversation keeps only the answer. The Appearance window holds the theme colour, the ground colour and the dithered photo. Closing a feature window hides it. Minimizing an agent never stops its work.

Provider key overrides last only for this server lifetime. Archive hides a saved session without deleting it. Workspace/session/provider changes require idle agents.

This release does not attach to unrelated terminal or pi-subagents sessions. OAuth login, arbitrary custom providers, session-tree editing and images remain terminal features. Installed Pi packages load for the main agent; project-local .pi resources stay untrusted.

The main agent loads every package configured in your Pi profile, so installed tools (for example web search) and pi-subagents load normally; a bundled pi-subagents fallback is used when the profile does not configure one. Its delegated agents follow their configured permissions. Automatic DELEGATED observer windows appear on the right in the former Scout/Review positions and show their available live output and results without launching extra agents. Closing an observer only dismisses the view; use the extension to stop its task. Minimize keeps it in the taskbar. Tools shows loaded packages and load errors; restart the app after installing one.

Expand Inspection in a subagent window for its available assigned/delivered prompt, tool-call previews, attributed file-change evidence, tokens, cost and elapsed wall time. Unknown is not zero. Live counters stay provisional until final usage is reported; some upstream prompts and async metrics are unavailable. Shared workspace Git changes are not attributed to a child.

Dropdown controls and their menus use the same retro style. Arrows/Home/End navigate, Enter/Space selects, Escape or Tab cancels tentative changes, and typing searches options. The native select remains the form's source of truth.

Tools selections change only the selected session after explicit Apply. Select none to disable all tools; main can use every tool from the packages installed in your Pi profile, while manual desktop subagents can only select from their read-only catalog.

Window types have distinct size presets; your manual layout wins. The desktop chrome and ground colours are yours in Appearance, along with an optional photo that is stored locally and never uploaded. The photo becomes a point cloud background: moving the pointer pushes or pulls it with the same spring-and-force motion as the reference field, and it settles back exactly when the pointer leaves. The same window can add an extra drifting particle field, whose dots link and collide while it drifts.
