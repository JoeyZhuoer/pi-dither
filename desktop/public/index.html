Desktop / Field guide

Your main agent gets the big window.

Drag title bars. Resize from the lower-right corner. Minimize to the taskbar. Any manual resize is saved for that window. Hidden windows stay hidden. Arrange resets the layout.

The desktop usage chart follows the selected agent. Click its heading for details.

Keyboard: focus a title bar and use arrow keys to move; Shift + arrows to resize. Ctrl/Cmd + Enter sends a message.

Press Ctrl/Cmd + F in the main window to search the whole conversation — answers, reasoning and tool output. Enter and Shift + Enter step through matches, Escape closes and clears the search.

Use + Subagent to create a manual draft, then Launch to start it. They are separate core Pi sessions defaulting to read, grep, find and ls tools.

The main agent defaults to Pi's filesystem and shell tools.

Use Windows for the windows you keep, and the ⚙ button on the right to choose which of them appear in the bottom bar and to open any of them. The Appearance window holds the theme colour, the ground colour and the background photo. Closing a feature window hides it. Minimizing an agent keeps its work running.

Workspace, session and provider changes require idle agents.

Installed Pi packages load for the main agent; project-local .pi resources stay untrusted.

Automatic DELEGATED observer windows show their live output and results. Minimize keeps it in the taskbar. Tools shows loaded packages and load errors; restart the app after installing one.

Expand Inspection in a subagent window for its assigned/delivered prompt, tool-call previews, file-change evidence, tokens, cost and elapsed wall time.

Dropdown controls and their menus use the same retro style. Arrows/Home/End navigate, Enter/Space selects, Escape or Tab cancels tentative changes, and typing searches options. The native select remains the form's source of truth.

Tools selections change only the selected session after explicit Apply. Select none to disable all tools.

Window types have distinct size presets; your manual layout wins. Appearance holds the colours, the background photo and the extra particle field.
