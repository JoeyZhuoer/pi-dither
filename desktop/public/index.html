Desktop / Field guide

Your main agent gets the big window.

Drag title bars. Resize from the lower-right corner. Minimize to the taskbar. Arrange restores the composition.

Keyboard: focus a title bar and use arrow keys to move; Shift + arrows to resize. Ctrl/Cmd + Enter sends a message.

Subagents run only when you press Launch. They are separate core Pi sessions with read, grep, find and ls tools—no concurrent file writers. Their results can be inserted into the main draft for your review.

The main agent retains Pi's filesystem and shell tools. This local interface is not a sandbox. Model requests use your configured Pi provider. Authentication stays on the server.

This release does not attach to existing terminal or pi-subagents runs. Terminal-only commands, session-tree editing, and arbitrary extensions remain available in the terminal app.
