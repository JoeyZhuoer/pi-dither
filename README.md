# Pi Terminal UI

A local, terminal-native redesign of core Pi, inspired by the dark terminal-brutalist visual language described in the TypeSafe design research.

## Scope

- **Interface:** terminal UI, not a browser frontend.
- **Required foundation:** core Pi and its coding-agent workflow.
- **Deployment:** local, single-user operation.
- **Visual direction:** near-black surfaces, warm off-white text, thin dividers, compact system labels, and restrained motion, adapted to terminal capabilities.
- **Usability:** prioritize readable output, keyboard interaction, and truthful execution status over decorative effects.

A browser frontend, cloud deployment, and third-party extension integrations are outside the initial scope.

## Status

Workspace and GitHub repository setup only. No implementation, dependency installation, or subagent work has started. Further planning and implementation await explicit instruction.
